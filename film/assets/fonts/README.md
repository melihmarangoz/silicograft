# Fonts

`MonaSans-latin-var.woff2`: Mona Sans (GitHub), the variable font (wdth 75-125, wght 200-900),
Latin subset as served by Google Fonts (`fonts.gstatic.com/s/monasans/v4/o-0IIpQmx24alC5A4PNr5TRA.woff2`,
downloaded 2026-11-08). The website's font (`site/tokens.css`, `--font-display`). SIL Open Font
License 1.1: the full text is in `OFL-MonaSans.txt` next to it. Used by the cell-type labels (pass 4,
`compositions/dive.html`).
